# Hello Programming

A hands-on introduction to 77 languages and technologies, from everyday programming and modern web frameworks to scientific computing, infrastructure, hardware, and smart contracts. Each entry pairs a `Hello, World!` greeting example with a concise, commented `examples` file introducing the basics and distinctive features of that language or tool, plus a guide with official documentation and run or usage instructions.

Start with a category below, open a language folder, and explore its examples. Introductory files are kept under 100 lines, generally around 50–65, so you can read, change, and revisit them in small steps. Some examples run independently; frameworks, databases, and specialized platforms require the host environment described in their guides.

## Languages and technologies

This single tree mirrors the collection's category and example folders. Categories describe primary uses, not exclusive capabilities: languages such as C++ and C# can also be used for games, but appear once in their existing folders. Supporting assets and repository checks are omitted from this learning map.

Icons are logo-only artwork from [Devicon](https://devicon.dev/); compact local lettermarks identify entries without a matching logo. Every folder and language name links to its directory.

## Verify the collection

On Windows, run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/verify-repository.ps1
```

This checks the collection structure, greeting sources, introductory-file links and line limits, and the tree's directory links. It does not compile or execute every language; follow each entry's guide to run its examples in the appropriate environment.
