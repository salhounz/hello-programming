# OCaml

OCaml is a functional-first language used for compilers, analysis tools, and reliable applications.

Official documentation: [OCaml documentation](https://ocaml.org/docs)

Run: `ocaml hello.ml`

## Concise introductory examples

[examples.ml](./examples.ml) introduces typed records, strings, booleans, lists,
comments, functions, pattern matching, pipelines, immutable record updates,
folding, the `Map.Make` functor, and option-based lookup results.

From this directory, run `ocaml examples.ml` with OCaml 4.05 or later (for
`Map.find_opt`). It needs only the standard library and prints a shelf catalog,
available titles, empty-list handling, and an original and updated record.
