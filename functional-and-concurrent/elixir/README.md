# Elixir

Elixir is used for fault-tolerant concurrent applications on the Erlang VM.

Official documentation: [Elixir documentation](https://hexdocs.pm/elixir/)

Run: `elixir hello.exs`

## Concise introductory examples

[examples.exs](./examples.exs) introduces strings, atoms, booleans, maps, lists,
comments and documentation, function clauses, pattern matching, pipelines,
immutable updates, case expressions, and a locally awaited task.

From this directory, run `elixir examples.exs` with Elixir and Erlang/OTP available.
No Mix project or dependencies are required. The script prints a shelf catalog,
available titles, lookup results, and a count returned by the task.
