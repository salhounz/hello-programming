# Julia

Julia is designed for numerical, scientific, and high-performance computing.

Official documentation: [Julia documentation](https://docs.julialang.org/)

Run: `julia hello.jl`

## Introductory examples

Keep [hello.jl](./hello.jl) as the minimal greeting. Open [examples.jl](./examples.jl) for a separate, commented introduction:

- Types and missing values; arrays, dictionaries, and named tuples; functions and dispatch; comprehensions and broadcasting.
- Small values and visible output you can change while learning; no external data files or additional packages are needed.

Run from this directory:

```sh
julia examples.jl
```

Read the numbered sections in order, then rerun after changing one value or expression. See [Julia manual](https://docs.julialang.org/en/v1/manual/) for more detail.
