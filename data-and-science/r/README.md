# R

R is used for statistics, data analysis, and scientific visualization.

Official documentation: [R manuals](https://cran.r-project.org/manuals.html)

Run: `Rscript hello.r`

## Introductory examples

Keep [hello.r](./hello.r) as the minimal greeting. Open [examples.r](./examples.r) for a separate, commented introduction:

- Atomic types, coercion, and missing values; vectors, lists, data frames, and factors; functions, indexing, and vectorized operations.
- Small values and visible output you can change while learning; no external data files or additional packages are needed.

Run from this directory:

```sh
Rscript examples.r
```

Read the numbered sections in order, then rerun after changing one value or expression. See [An Introduction to R](https://cran.r-project.org/doc/manuals/r-release/R-intro.html) for more detail.
