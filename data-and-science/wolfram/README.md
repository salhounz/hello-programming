# Wolfram Language

Wolfram Language is used for symbolic computation, mathematics, and computational notebooks.

Official documentation: [Wolfram Language documentation](https://reference.wolfram.com/language/)

Run: `wolframscript -file hello.wls`

## Introductory examples

Keep [hello.wls](./hello.wls) as the minimal greeting. Open [examples.wls](./examples.wls) for a separate, commented introduction:

- Expression heads, exact numbers, and missing values; lists and associations; pattern-based and pure functions; local scope; symbolic expressions and replacement rules.
- Small values and visible output you can change while learning; no external data files or additional packages are needed.

Run from this directory:

```sh
wolframscript -file examples.wls
```

Read the numbered sections in order, then rerun after changing one value or expression. See [Wolfram function definitions](https://reference.wolfram.com/language/ref/SetDelayed.html) for more detail.
