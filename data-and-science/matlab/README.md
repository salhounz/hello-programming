# MATLAB

MATLAB is used for numerical computing, engineering, simulation, and data analysis.

Official documentation: [MATLAB documentation](https://www.mathworks.com/help/matlab/)

Run: `matlab -batch "run('hello.m')"`

## Introductory examples

Keep [hello.m](./hello.m) as the minimal greeting. Open [examples.m](./examples.m) for a separate, commented introduction:

- Numeric, logical, and text types; matrices, cells, structs, and tables; logical indexing; anonymous and local functions; element-wise versus matrix operations.
- Small values and visible output you can change while learning; no external data files or additional packages are needed.

Run from this directory:

```sh
matlab -batch "run('examples.m')"
```

Read the numbered sections in order, then rerun after changing one value or expression. See [MATLAB local functions](https://www.mathworks.com/help/matlab/matlab_prog/local-functions.html) for more detail.
