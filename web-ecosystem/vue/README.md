# Vue

## Concise introductory examples

[examples.vue](./examples.vue) introduces typed records, comments, functions, arrays, refs, computed values, v-model, v-for keys, v-if/v-else, events, and scoped styles.

Use an existing Vue 3 Vite TypeScript application with dependencies installed. Copy the file to `src/examples.vue`. In `src/App.vue`'s `<script setup>`, import `Examples` from `"./examples.vue"`, then render `<Examples />` in its template. From the app root run `npm run dev` and open Vite's printed URL (normally `http://localhost:5173`). Try changing read status, filtering, and resetting. The SFC compiler is supplied by the host project.

Vue is a progressive framework for building user interfaces with declarative, component-based templates. Nuxt adds full-stack and application conventions around Vue.
