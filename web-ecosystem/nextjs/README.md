# Next.js

## Concise introductory examples

[examples.tsx](./examples.tsx) introduces a typed App Router page, record collections, functions, component props, comments, filtering, conditional JSX, list keys, and Set.

Use an existing Next.js App Router TypeScript application with dependencies installed and a root layout. Copy this file to `app/examples/page.tsx` (or `src/app/examples/page.tsx` if the app uses `src`). From the app root run `npm run dev` (a script invoking `next dev`) and open `http://localhost:3000/examples`. It is a Server Component with local data; edit `onlyUnread` in the source to change the filter. The native disclosure needs no client component.

Next.js is a React framework for full-stack web applications. It adds routing, server rendering, static generation, and optimized production builds.

## Example

Use: Place [hello.tsx](./hello.tsx) in a Next.js App Router project as `app/page.tsx`, then run the project with its package script.
