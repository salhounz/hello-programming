# Svelte

## Concise introductory examples

[examples.svelte](./examples.svelte) introduces typed records, comments, functions, arrays, Svelte 5 state/derived runes, two-way checkbox bindings, keyed each blocks, conditionals, events, and scoped styles.

Use an existing Svelte 5 Vite TypeScript application with dependencies installed. Copy the file to `src/examples.svelte`. In the script of `src/App.svelte`, import `Examples` from `"./examples.svelte"`, and place `<Examples />` in its markup. From the app root run `npm run dev` and open Vite's printed URL (normally `http://localhost:5173`). Change read status, filter the list, and reset it. The example uses Svelte 5 runes, not the older reactive declaration syntax.

Svelte is a component framework that compiles declarative components into efficient JavaScript. SvelteKit adds routing and full-stack application features.

## Example

Use: Add [Hello.svelte](./Hello.svelte) to a Svelte or SvelteKit project and render it from a page.
