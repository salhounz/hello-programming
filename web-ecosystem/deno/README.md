# Deno

## Concise introductory examples

[examples.ts](./examples.ts) introduces typed records, comments, functions, arrays, filtering, Set, async functions, Promise.all, UTF-8 encoding, Response, and Deno runtime metadata.

With Deno 2.x, run `deno check examples.ts`, then `deno run examples.ts Ada` from this directory. No imports or permission flags are needed: the example uses only local values and in-memory web APIs. Its Response is not an HTTP request or server.

Deno is a secure-by-default JavaScript and TypeScript runtime with built-in tooling for formatting, testing, linting, and dependency management.

## Example

Run: `deno run hello.ts`

Learn more in the [Deno documentation](https://docs.deno.com/runtime/).
