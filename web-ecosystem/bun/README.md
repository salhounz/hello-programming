# Bun

## Concise introductory examples

[examples.ts](./examples.ts) introduces typed records, arrays, functions, conditionals, iteration, Set, command-line arguments, Response, and Bun's bundled SQLite API.

With Bun 1.x or later, run `bun run examples.ts Ada` from this directory. It creates an in-memory SQLite database, inserts records with bound parameters, queries unread books, closes the database, and prints JSON. No packages, disk database, server, or network access are required.

Bun is a JavaScript and TypeScript runtime, package manager, bundler, and test runner designed for fast local development and server-side applications.

## Example

Run: `bun run hello.ts`

Learn more in the [Bun documentation](https://bun.sh/docs).
