# SolidJS

## Concise introductory examples

[examples.tsx](./examples.tsx) introduces typed records, comments, functions, arrays, immutable updates, signals, memos, events, For, and Show.

Use an existing Vite Solid TypeScript application with dependencies installed. Copy the file to `src/examples.tsx`. In `src/App.tsx`, import `Examples` from `"./examples"` and return `<Examples />` from App. From the app root run `npm run dev` and open Vite's printed URL (normally `http://localhost:5173`). Toggle the checkboxes. Keep the host's Solid JSX compiler configuration; React JSX tooling cannot compile this component correctly.

SolidJS is a reactive UI library with fine-grained updates. It uses JSX while compiling components into efficient DOM operations.
