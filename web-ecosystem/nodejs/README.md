# Node.js

## Concise introductory examples

[examples.js](./examples.js) introduces CommonJS imports, values, functions, arrays, filtering, Set, CLI options, streams, async iteration, promises, and error exit codes.

From this directory with Node.js 18.3 or later, run `node examples.js --name Ada`; add `--all` to include read books. Try `node examples.js --unknown` to see a handled argument error with exit code 1. It uses built-in modules only and reads or writes no files.

Node.js is a JavaScript runtime built on V8. It provides event-driven APIs for servers, command-line tools, automation, and other applications outside the browser.
