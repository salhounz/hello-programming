# React

## Concise introductory examples

[examples.jsx](./examples.jsx) introduces values, comments, functions, component props, arrays, immutable updates, useState, controlled inputs, conditional JSX, and stable list keys.

Use an existing React Vite application with dependencies installed. Copy the file to `src/examples.jsx`. In `src/App.jsx`, import `Examples` from `"./examples.jsx"` and render `<Examples />` from the default App component. From the app root run `npm run dev` and open the URL printed by Vite (normally `http://localhost:5173`). Toggle read status and the unread filter. The existing entry point mounts App; this file exports a component rather than creating another root.

React is a library for building user interfaces from composable components. It is commonly paired with tools such as Vite, Next.js, or a custom framework for routing and application delivery.
